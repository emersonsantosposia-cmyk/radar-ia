# Radar de Casos de Uso de IA

Mural da turma: formulário que grava casos de uso no Supabase e lista os registros já publicados.

## Ambiente

Crie `.env.local` na raiz (não versionar):

```
NEXT_PUBLIC_SUPABASE_URL=https://SEU-PROJETO.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sua_chave_anon
```

Use só a chave **anon**. Não use `service_role`.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
